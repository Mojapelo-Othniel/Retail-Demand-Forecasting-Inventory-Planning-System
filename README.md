# Retail-Demand-Forecasting-Inventory-Planning-System
Problem

Retail businesses often struggle to accurately predict product demand, resulting in either excess inventory (increased holding costs) or stock shortages (lost sales). The objective of this project is to develop a forecasting model that supports better inventory planning and demand management.

Approach

The project follows a structured analytical workflow:

Data preprocessing and aggregation of daily sales
Exploratory data analysis to identify trends and seasonal patterns
Stationarity testing using rolling statistics and ADF tests
Time series decomposition to isolate trend and seasonality
Model development using ARIMA and Exponential Smoothing
Parameter selection using ACF and PACF analysis
Model evaluation using MAE and RMSE metrics

Results

The ARIMA model successfully captured both trend and seasonal components of the data, producing reliable forecasts on unseen data. Model performance was evaluated using standard forecasting metrics, demonstrating the model’s ability to generalise to future demand patterns.

Business Impact

This solution enables businesses to:

Anticipate demand fluctuations
Optimise inventory levels
Reduce stock shortages and overstock risk
Support data-driven operational planning
